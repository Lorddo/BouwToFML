# Aanvullende klantwensen (ruwe notities)

**Verwerkt in:** `.cursor/docs/klant-eisen-v1.md` (jun 2026)

---

We focussen nu op 1 type klant dat 1 template heeft:

**Fase 1:** wanden, ramen en deuren.

- Hoogte muren (vloer tot plafond): handmatig
- **Muren:** na detectie bepaalt tekenaar buitenmuur / woningsscheidend / binnen + diktes (3 defaults cm)
- **Ramen:** controle + toevoegen (icoon) + refresh learn-by-example
- **Deuren:** controle + toevoegen + refresh; tags voordeur / achterdeur / binnendeur + maatvoering per type
- **Bovenlicht:** V1 indien haalbaar, anders V2
- **Roomtag:** vaste lijst uit tekenprotocol → Floorplanner (`areas[]`)
- **FP-tags export:** muren/deuren indien mogelijk in FML

**Fase 2 (V2):** keukenblok detectie (180 cm), sanitair (toilet, fontein, wastafel, douche, bad)
